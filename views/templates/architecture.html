Standalone
1. Presentation Tier

Encapsulated in views/. Dispatches user requests, handles session cookies, and renders real-time visual feedback.

  • Zero-Friction Guest Mode: Run experiments directly without account barrier.
  • REST API: POST /api/run-simulation returns JSON with qubit traces.
  • SVG Photon Visualizer: Synchronized animation of states, polarization, and attacks.
2. Quantum Domain Tier

Encapsulated in business/. Contains physical quantum protocol modeling, noise simulation, and metrics.

  • Qiskit Circuit Prep: Single-qubit circuits in rectilinear ($Z$) and diagonal ($X$) bases.
  • Depolarizing Channel: NoiseModel simulating optical loss and decoherence.
  • Devetak-Winter Key Rate: $R_\infty = \max(0, 1 - 2h(\text{QBER}))$ with 11% cutoff.
3. Data & Migrations Tier

Encapsulated in datos/. Clean repository pattern abstracting SQLite/PostgreSQL persistence and schema evolution.

  • Repository Pattern: session_repository.py and user_repository.py.
  • Runtime Schema Migrator: datos/esquema.py adds missing columns dynamically.
  • Audit Log: Tracks noise rates, sample sizes, QBER, and secret key rates.
